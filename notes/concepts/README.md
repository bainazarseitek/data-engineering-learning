# Concept notes

One file per concept, for example `cdc.md`, `dlq.md`, `idempotency.md`, `kafka-vs-rabbitmq.md`. The full list of 25 is in section 10 of the master plan. Tick a concept there only when its file here is complete.

Template:

```markdown
# <Concept>

**Problem it solves:** one sentence.
**How it works:** 3-5 lines, in my own words.
**Trade-offs:** what it costs.
**Alternatives:** what else I could use, and when.
**Typical interview question:** ...
**My answer in 2 minutes:** ...
**My story:** where I used it (Mercedes or a project). If none yet, which project will give me one.
```
